# Research Summary: Retinal Information Processing

## Research Question

How can simplified computational models help explain the way retinal systems preserve signal fidelity while processing noisy biological information?

## Project Overview

This project explores retinal information processing through Python-based simulations of signal propagation, biological noise, dimensionality reduction, frequency analysis, receptive fields, spike trains, and filtering.

## Methods

I used NumPy, Matplotlib, Pandas, and scikit-learn to model and visualize simplified retinal signal behavior. Each notebook focuses on a different computational idea related to vision and neural information processing.

## Key Concepts Modeled

- Signal visualization
- Retinal layer propagation
- Biological noise
- PCA dimensionality reduction
- Fourier frequency analysis
- Center-surround receptive fields
- Spike train modeling
- Signal filtering

## Reflection

This project helped me move from simply visualizing biological patterns to asking how neural systems preserve structure under noise. It connects my interests in biology, computation, and vision by treating the retina as an information-processing system.

## Future Work

Future directions include applying these methods to real retinal gene-expression datasets, exploring clustering methods, and building more biologically realistic models of retinal computation.
