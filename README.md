# Retinal Information Processing

This repository documents my early computational neuroscience and biological signal processing work focused on retinal information flow, neural variability, and dimensionality reduction.

## Research Motivation

The retina is not simply a passive detector of light. It performs layered biological computation that transforms noisy sensory input into stable neural representations. This project explores simplified computational models of retinal signal propagation and analysis using Python.

## Current Notebooks

### 01_signal_visualization.ipynb
Introduces biological signal visualization using NumPy and Matplotlib.

Topics:
- Signal generation
- Time-series visualization
- Retinal-inspired waveform simulation

---

### 02_retinal_dataset_loading.ipynb
Simulates retinal signal propagation across simplified retinal layers.

Modeled components:
- Photoreceptors
- Bipolar cells
- Ganglion cells

---

### 03_retinal_noise_modeling.ipynb
Explores how biological noise alters retinal signal fidelity.

Topics:
- Noise injection
- Signal degradation
- Biological variability
- Signal-to-noise relationships

---

### 04_pca_signal_analysis.ipynb
Uses Principal Component Analysis (PCA) to study dimensional structure in simulated retinal signals.

Topics:
- Dimensionality reduction
- Variance structure
- Neural representation analysis
