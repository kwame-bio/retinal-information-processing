# Retinal Information Processing

This repository documents my early computational biology work on retinal signal processing, biological information flow, and neural systems modeling.

## Current Notebooks

### 01_signal_visualization.ipynb
Introduces basic signal visualization using Python, NumPy, and Matplotlib.

### 02_retinal_dataset_loading.ipynb
Simulates signal propagation across retinal cell layers:
- Photoreceptors
- Bipolar cells
- Ganglion cells

## Research Direction

This project is part of a broader interest in how biological systems preserve reliable information processing across neural circuits, especially in vision.

## Tools Used

- Python
- Jupyter Notebook
- NumPy

- Matplotlib
