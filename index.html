Retinal Information Processing

Independent computational neuroscience portfolio exploring retinal signal propagation, biological noise, dimensionality reduction, clustering, gene-expression simulation, and neural information processing.

View GitHub Repository

Research Motivation

This project studies the retina as an information-processing system. Through Python-based simulations and analysis, I explore how biological systems preserve reliable signals under noisy and variable conditions.

Notebook Portfolio

Signal Visualization

Introduces simulated retinal signal visualization.

Retinal Signal Propagation

Models photoreceptor, bipolar, and ganglion-cell signal flow.

Noise Modeling

Explores how biological noise affects retinal signal fidelity.

PCA and Clustering

Uses dimensionality reduction and machine learning to study retinal signal structure.

Gene Expression Simulation

Simulates retinal cell-type gene-expression patterns using PCA and clustering.

Future Work

Future extensions include real retinal datasets, neural population analysis, biological image processing, and more realistic computational vision models.
